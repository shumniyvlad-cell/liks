# Шаблон March: приложение на Astryx

Стек как у SGX: React 19 + TypeScript + Vite, компоненты и окна из Astryx (дизайн-система Meta), своя тема `march`. Без Tailwind и shadcn: два набора компонентов дают два набора скруглений и цветов.

Демо — полноценное приложение «Катки»: главная (фото зала, «свободно сейчас», акции, афиша, зоны, новости), афиша с записью на события, брони с билетом ближайшей, профиль (карта гостя, баллы, уровень, абонемент, приглашение друга, тема, напоминания). Снизу стеклянный док, в центре кнопка «Записаться».

Свой CSS только в `src/app.css`: стекло (`.glass`, `.glass-photo`), фото с наложением, док и ленты. В Astryx нет материала стекла. Цвета там только из токенов темы. Стекло — на панелях поверх фото и контента, не на пустых карточках.

## Переодеть под клиента
1. `src/business.ts` — название, адрес, телефон, часы, зоны и цены. Бизнес-названия в остальном коде не пишем.
2. `public/demo/` — фото клиента (свои, не заглушки).
3. Акцент и вид — только через редактор темы, потом смотреть PNG:
   `npx astryx experimental theme editor set march accent "#hex"` → `npx astryx experimental theme editor show march --png`.
   На светлом акценте текст кнопки тёмный: `--color-on-accent`.
4. `src/api.ts` — демо-сервер в браузере, `src/store.ts` — профиль и настройки; в бою меняются на Supabase, интерфейс не трогаем.
5. Любой новый лист снизу подключай к `useSheetBack`, чтобы «Назад» телефона его закрывал.

## Правила окон (из промпта SGX, держать на каждом экране)
- Каждый шаг формы — свой BottomSheet, один state называет открытый шаг; «Назад» телефона закрывает лист.
- У каждого сетевого экрана четыре состояния: загрузка (Skeleton), ошибка с «Повторить», пусто с действием, готово.
- Ошибки у поля, фокус на первое поле с ошибкой; кнопка с isLoading во время запроса; отмена через AlertDialog и тост с «Вернуть».
- Один главный CTA на экран, один акцент, без градиентов, капса с разрядкой, точек-разделителей и стекла на пустых карточках.

## Проверка перед сдачей
`npx tsc -b && npm run build && npx astryx doctor --built dist && npm audit`, затем ui-ux-pro-max и web-design-guidelines по экранам, телефон 390 в тёмной и светлой теме. Ошибки показать: `?fail=slots`, `?fail=book`.
